# WEB-Z1
Задание номер 1. WEB 
AI-ассистент (DeepSeek) использовался для генерации базовой структуры HTML, написания CSS-стилей по макету (темная тема, неоновые акценты) и создания логики JavaScript. и
HTML5/CSS3/JavaScript стандартный стек для верстки. HTML отвечает за структуру, CSS за адаптивность (Mobile First) и визуал, JS за интерактивность.

VS Code / GitHub Codespaces используемые среды разработки для редактирования кода.

GitHub Pages хостинг для публикации готового сайта.

Запрос: «Создай одностраничный сайт-портфолио по макету (темная тема, неоновые акценты). Верстка должна быть выполнена по принципу Mobile First с использованием стандартного стека HTML, CSS, JS».

Результат проверки: Код успешно сгенерирован и адаптирован. Проверка проводилась в браузере на разрешениях 375px (мобильный), 768px (планшет) и 1920px (десктоп). Ошибки в консоли JavaScript отсутствуют. Сайт успешно развернут на GitHub Pages.

Вручную был корректирован футер и текст в нем, изменен текст в информации профиля
